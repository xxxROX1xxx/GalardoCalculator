# Galardo

Локальный журнал сделок: покупки, продажи, комментарии, фотографии и итоговая
прибыль. История хранится в SQLite и **не пропадает после закрытия программы**.

## Возможности

- форма сделки: товар, «Купил / Продал», сумма, категория
  (транспорт / одежда / предметы), дата и время, комментарий;
- фото сделки: `Ctrl+V` из буфера обмена (работает, даже если курсор стоит в
  поле названия), клик по полю открывает стандартный выбор файла, также
  работает перетаскивание;
- при первом запуске история старой версии **Calculating** автоматически
  переносится в Galardo вместе с фотографиями;
- вкладки «История», «Транспорт», «Одежда», «Предметы», «Маркет»: общая
  история плюс фильтр по категории;
- вкладка «Маркет»: поиск по одежде, предметам и транспорту сервера
  **Phoenix (RU15)** — средние, минимальные и максимальные цены, продажи и
  график за 30 дней (данные m5rp.ru);
- сделки в каждой вкладке сгруппированы по неделям от первой сделки: свежая
  неделя раскрыта, прошлые свёрнуты (заголовок недели можно нажать);
- окно разворачивается на весь экран кнопкой в шапке или двойным кликом;
- история с поиском по названию и комментарию;
- быстрые кнопки «Продал такое» / «Купил такое»: подставляют данные прошлой
  сделки в форму, и вы можете изменить сумму, комментарий и фото перед
  сохранением;
- редактирование и удаление записей;
- итог: продажи минус покупки, с подсветкой прибыли/убытка (всё в долларах);
- оформление: кнопка-шестерёнка в шапке — чёрная или белая тема, вторичный
  цвет (6 готовых или любой свой) и логотип GALARDO на фоне в чёрной теме
  (в белой — чёрная надпись GALARDO);
- горячие клавиши: `Ctrl+V` — фото, `Ctrl+Enter` — внести сделку,
  `Esc` — отменить редактирование или очистить подставленные данные.

## Запуск готовой программы

`dist\Galardo.exe` — двойной клик, установка не требуется.

Данные лежат в `%APPDATA%\Galardo\galardo.db` (фото — в той же базе).
Для резервной копии достаточно скопировать этот файл.

При первом запуске Galardo сама переносит историю старой версии **Calculating**
из `%APPDATA%\Calculating\transactions.json` — вместе с фотографиями. Повторно
одни и те же сделки не добавляются.

## Маркет (Phoenix / RU15)

Вкладка «Маркет» показывает статистику маркетплейса с открытых страниц
[m5rp.ru](https://m5rp.ru): каталог одежды, предметов и транспорта, 30-дневные
агрегаты (средняя / мин. / макс. цена, число продаж) и дневную историю.

- поиск визуально по центру, разделы переключаются чипами
  «Одежда / Предметы / Транспорт»;
- миниатюры одежды, предметов и транспорта; клик по картинке открывает её
  крупно (закрыть — клик в любом месте или `Esc`);
- клик по строке открывает карточку: сводка за 30 дней, график средней цены
  и объёма продаж, таблица по дням с изменением объёма за сутки;
- в карточке можно сразу записать сделку: «Купил / Продал», цена за 1 шт.,
  количество и комментарий. Под ценой видно, на сколько она отличается от
  средней рыночной (в процентах и сумме) и выгодна ли для выбранной стороны;
  кнопки «Средняя / Мин. / Макс.» подставляют цену из сводки;
- сделка из маркета попадает в журнал с текущей датой и нужной категорией:
  сумма = цена × количество, количество сохраняется в сделке, а при
  количестве больше 1 в комментарий добавляется «N шт. × цена». Фотография
  предмета прикрепляется к сделке автоматически — как если бы вы добавили её
  вручную. Позже сделку можно открыть в истории и отредактировать;
- «Мин.» и «Макс.» — крайние цены **среди всех продаж за 30 дней**, поэтому
  разброс вокруг средней бывает большим;
- в источнике число продаж — скользящее окно на 30 дней, а не продажи за
  конкретный день; отсюда подпись «За 30 дн.» и деление на 30 при оценке
  «≈ N в день»;
- сейчас поддержан только сервер Phoenix (в игре — RU15), другие серверы
  появятся позже.

Часть вещей в источнике вообще без названия (`#4-82`, `#11-22` и подобные):
это базовая одежда GTA, у неё нет имён ни в JSON m5rp, ни в официальной вики.
Вместо технического кода показывается слот, модель и цвет — например,
«Штаны · модель 82 · цвет 4» или «Верх · модель 22 · цвет 1»; в карточке
добавляется пол. Для кастомных вещей, которых нет в m5rp, названия и картинки
дополнительно берутся из официальной вики Majestic (`galardo/clothing_wiki.py`,
только недостающие записи). У предметов без названия вместо `#1276` —
«Предмет · ID 1276» с пометкой «нет названия в источнике».
Если картинки для такой вещи нет, остаётся буква-заглушка. Когда картинка
не загрузилась из-за обрыва связи, приложение само повторяет запрос.

Данные кэшируются в `%APPDATA%\Galardo\market`: каталог — на 6 часов,
история — на 5 минут. Кнопка «Обновить» перезагружает каталог с сайта; если
сети нет, показываются последние сохранённые данные. Дневная история в
источнике ведётся с конца октября 2026, поэтому у предметов может быть меньше
30 дней, а у редких — ни одного (тогда в карточке будет пометка об этом).

## Запуск из исходников

Нужен Python 3.10+ и [uv](https://docs.astral.sh/uv/).

```bat
uv venv .venv --python 3.13
uv pip install -r requirements.txt
.venv\Scripts\python.exe main.py
```

Или просто `run.bat` после сборки окружения.

## Сборка exe

```bat
build.bat
```

Скрипт создаст окружение, поставит зависимости, сгенерирует иконку и соберёт
однофайловый `dist\Galardo.exe` через PyInstaller. Пересобирать после изменений
кода — тем же `build.bat`.

## Структура

- `main.py` — точка входа, тема, запуск окна;
- `galardo/db.py` — SQLite-хранилище;
- `galardo/mainwindow.py` — окно, форма и история;
- `galardo/market.py` — вкладка «Маркет»: каталог m5rp.ru, кэш, график и
  карточка предмета;
- `galardo/widgets.py` — карточки, календарь, фото, тосты;
- `galardo/theme.py` — чёрная и белая QSS-темы, акценты, палитра;
- `galardo/icons.py` — векторные иконки и логотип;
- `tools/make_icon.py` — генерация `assets/galardo.ico`.
